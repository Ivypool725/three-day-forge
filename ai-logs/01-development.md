# 开发过程与协作修改

| 阶段 | 提出的问题与处理结果 | 可追溯的修改 |
|---|---|---|
| 最初的经营循环 | 在课程模板上实现三天九单、三锤定品质、按件结账、取证和分支结局。 | `e7e19bb`、`dbe8004` |
| 工序连续性 | 将原先分开的工序收进同一个铺面。点炉、铁砧和水槽依次操作，放大工位字和捶打图案。结合组员调整的铺面与柜台对话。 | `c8377dc`、`11e6296`、`f9d523f`、合并 `8644cca` |
| 锻造难度 | 按器型和日期调整绿区宽度，每锤换位置，放慢指针；三锤全红允许付少量银钱换料返工。 | `e7df37e`、`d39fd5e` |
| 声音和画面对位 | Git 记录中 `humanoid-konjac` 接入炉火与淬火音效，并修正锻造和淬火工位的画面对齐。随后修复音效打断工序。 | `1d89585`、`2d020c7`、`e51ffc7` |
| 顾客与存档 | 先点击来客才进入双人立绘对话。合入在线柜台对话、场景背景和四格存档后，保留离线预写对白。 | `189e92c`、`9b79664` |
| 支线与结局 | 为五位顾客加入可兑现的约定和协助，新增证词和联保、递证结局。随后把支线与证词改为学徒发问、顾客回答的双人对话，恢复打烊后的夜间后院图。 | `8ea1fff`、`5bb6c42`、本次提交中的 [支线规则](../src/core/side-stories.ts) 与 [场景实现](../src/scenes/play.ts) |

本项目的 Codex 使用范围包括按需求改动代码、检查回归和整理说明。个人贡献以实际 Git 提交和小组署名为依据。
