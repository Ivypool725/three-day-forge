师傅留下了一封信。今天起，你要独自替他看三天铺子。客人怎么评价你的手艺、打烊后你愿意停下来看什么，都会改变第三日黄昏的结果。

**电脑离线试玩**。解压课程提交包后双击 `release/index.html`。从 GitHub 下载的是源码，在项目目录运行 `npm ci` 和 `npm run pack` 即可生成同一个离线入口。

**API 可选**。离线用预写的对白和提问选项，可完成三天九单、五条支线并解锁全部六种结局。接入 API 后可自由向顾客提问，顾客会结合身份、已发生的对白和上次交付来回答，推荐问法也随对话更新。两种模式共用锻造、取证、支线和结局判定。

## 第一次看店

从“推门开铺”开始。每位来客都会先停在上门提示，点「上前交谈」后才开口，当前说话的角色立绘会亮起。在线时可直接向顾客提问，离线时可点选一句对白，聊完再接单。点炉加热，等指针进入绿区时敲锤，三次后点水槽淬火，验货后回到柜台与顾客交谈。每锤之后绿区换边，器型越难、日子越往后，绿区越窄。绿区每锤得 2 分，黄区 1 分，红区 0 分。瑕疵件也能交，少收些银子，街坊会记得。三锤全红时铁坯会碎，换料重锻最多扣 0.5 两，余额为零时可以免费重来。

点画中的工具或操作按钮均可，落锤也可用空格。封面提供四格本地存档，各步自动保存到当前栏位。手记可以查看委托、账目、证物、证词和来客的约定。阅读不计时。

**源码运行**需要 Node 22.12 或以上的 22.x 版本，或兼容的新版本。在项目目录执行：

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。类型与规则检查用 `npm run check`，构建用 `npm run build`。电脑端自动试玩使用系统 Chrome，示例命令为 `node tools/playthrough.mjs http://127.0.0.1:5173 expose desktop`。

**支线与结局**。柜台出现支线或证词选项时，点开可看学徒和顾客轮流说话。听完并记入手记后可回到柜台。兑现顾客的委托约定可获得他们的信任，银两、口碑、物证和来客支持共同决定终局可选的行动。

**三天九单的柜台交谈**　五位顾客各有要办的事。到柜台先读顾客当前的对白。在线时直接输入并发送，也可点输入框上方的参考问法，改成自己的说法再发送。最多显示两条切入点不同的 AI 推荐，顾客答完后按已出现的对白更新。下排保留一条固定引导。推荐暂未生成时可点“重新推荐”。左侧会马上显示玩家的问题，顾客每轮回答一句，随模型返回逐段出现。听见特定细节后，上方会出现可追问的参考问法。当前顾客的完整对白可点“对话记录”。点“接下这单”，选定柜台约定后开炉，顾客在验货时会回应成色和约定。回头客能聊上次交付的结果。手记可展开每一单，重读自己的问题、顾客原话和当时的选择。关键证物要在对应场景亲手查看、收下。

**在线交谈**　在本机项目根目录的 `.env` 设置 `KSYUN_API_KEY` 后重启开发服务。问单接口 `/api/customer/ask` 使用课程模型 `mimo-v2.6-flash`，带上当前来客的角色设定、最近六轮对白。回访时还可带上同一来客上一单的约定和最后两轮原话。每单最近十二轮保存在本机。参考问法由 `/api/customer/suggestions` 在后台生成，带上本单的委托与主线方向、当前顾客的开场和最近三轮已发生的对白。剧情方向用来选题，已出现的对白用来核准事实。固定引导由界面单独显示，浏览器会在收到推荐后过滤与引导重复的问法。验货接口为 `/api/customer`。离线或未配置模型时，柜台直接使用独立的预写对白选项，点选即可交谈。离线包可以走完所有问法分支和结局。

## 工程分工与维护入口

在线试玩用的 `.env` 只保存在本机。组员可在本机的 `.git/info/exclude` 中加入 `.env` 和 `.env.*`，再填写课程 Key。

| 入口 | 内容 |
|---|---|
| `src/core/orders.ts`、`story.json` | 九单、证物文本、信、威胁、夜探和结局台词 |
| `src/core/visits.ts`、`server/visits.mjs` | 九次进店的角色事实、可追问细节、柜台约定和同客回访 |
| `src/core/side-stories.ts` | NPC 支线、兑现约定与协助条件 |
| `src/core/game.ts` | 判定区、三锤品质、逐单账本、收支、证物解锁和结局门槛 |
| `src/scenes/`、`src/style.css` | Phaser 场景、响应式按钮和手记、同步打击与剧情演出 |
| `src/engine/`、`assets/manifest.json` | 课程模板的资源预载、图像与音频、自适应画布和本地存档 |
| `server/customer.mjs`、`vite.config.ts` | 服务端模型代理、输入检查和回退；开发和预览服务可用 |
| `tests/`、`tools/playthrough.mjs` | 规则边界、模型模拟、正常界面从开局到结算的重放 |

## 素材来源与使用范围

| 资产 | 来源、使用范围与加工 |
|---|---|
| 晨光铺面、夜色后院、六人肖像 | 本项目调用 Codex ImageGen 生成。两幅场景转换为 WebP，人物按六格切分为独立肖像，去除背景后用于对白 |
| 炉、水槽、器物、火花与蒸汽图 | 课程提供的“网页游戏起步模板”美术。按课程作业范围使用，运行清单在 `assets/manifest.json`，其余模板素材随源码保留 |
| 铁砧、热料、锤子 | 课程“参考素材/2D图片/items_atlas.png”及其 JSON，按原图集裁切透明图形。用于课程项目 |
| 学徒对白立绘 | 本项目以现有角色肖像为画风参考，用 Codex ImageGen 生成并转为保留透明背景的 WebP。 |
| 三日声景与叩门 | 本项目生成的拨弦旋律、其降调变奏、炉火环境声和三声木响。见[配乐与叩门制作脚本](tools/music.py)。金属声和钱币声采用课程模板 Web Audio 合成配方 |
| 点炉与淬火 | 项目成员提供的起火声与热铁入水声，分别存为 `furnace-ignite.mp3`、`quench.mp3`，在游戏中截取并淡入淡出 |
| 程序、字体 | 课程 Phaser＋TypeScript＋Vite 模板上开发；Phaser、Vite 为 MIT，TypeScript 为 Apache-2.0。使用设备提供的中文字体，包内未嵌入商业字库 |
| 世界观和人物文本 | 小组 WPS 定稿；游戏对白为面向交互篇幅的改写。大晟、青溪县和军器管制均采用该架空设定 |
