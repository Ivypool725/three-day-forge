**双击 [release/index.html](release/index.html) 即可离线开铺。** 师傅留下了一封信。今天起，你要独自替他看三天铺子。客人怎么评价你的手艺、打烊后你愿意停下来看什么，都会改变第三日黄昏的结果。

## 第一次看店

从“推门开铺”开始。听清来意再接单；点炉加热，看指针进入中央绿色刻纹时敲锤，三次后点水槽淬火，验货交给顾客。绿区每锤得 2 分，黄区 1 分，红区 0 分。瑕疵件也能交，少收些银子，街坊会记得。

点画中的工具或操作按钮均可，落锤也可用空格。手记里能重读师傅的信、对照每笔银两、再看收下的东西。阅读不计时。各步自动存档，重新打开后可继续看店。电脑和手机均可操作，手机横放能同时看清来客与订单。

**源码运行**需要 Node 22.12 或以上的 22.x 版本，或兼容的新版本。在项目目录执行：

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。手机与电脑在同一网络时，可用 `npm run dev -- --host 0.0.0.0`，在手机浏览器打开终端给出的 Network 地址。类型与规则检查用 `npm run check`，构建用 `npm run build`，重新生成离线单文件用 `npm run pack`。试玩器用系统 Chrome，命令示例为 `node tools/playthrough.mjs http://127.0.0.1:5173 expose mobile`。

**可选在线顾客回应**在项目根目录的本机 `.env` 设置 `KSYUN_API_KEY` 后重启开发服务，同源 `/api/customer` 会请求课程提供的 `mimo-v2.6-flash`。服务只发送当前普通顾客、本单器型、用途、天数和品质。界面先显示对应品质的本地台词；真实模型给出有效回复后更新为“AI 即兴”。空 Key、超时、错误、违规格式或离线文件模式均保留本地台词。关键证词、官差对白和结算走本地剧情。按组内安排，此包未设置 Key，本次未进行付费模型在线验收。

## 工程分工与维护入口

| 入口 | 内容 |
|---|---|
| `src/core/orders.ts`、`story.json` | 九单、证物文本、信、威胁、夜探和结局台词 |
| `src/core/game.ts` | 判定区、三锤品质、逐单账本、收支、证物解锁和结局门槛 |
| `src/scenes/`、`src/style.css` | Phaser 场景、响应式按钮和手记、同步打击与剧情演出 |
| `src/engine/`、`assets/manifest.json` | 课程模板的资源预载、图像与音频、自适应画布和本地存档 |
| `server/customer.mjs`、`vite.config.ts` | 服务端模型代理、输入检查和回退；开发和预览服务可用 |
| `tests/`、`tools/playthrough.mjs` | 规则边界、模型模拟、正常界面从开局到结算的重放 |
