# 五分钟现场展示提纲（主讲人自行练习）

| 时间 | 操作 | 可以讲的一句话 |
|---|---|---|
| 0:00～0:40 | 离线打开游戏，读老周的信 | “这是我第一次独立看店。师傅给了我三天，也留下一句别碰木箱。” |
| 0:40～1:40 | 完成第一单，先看清锻打条，再故意敲一锤黄区 | “每一锤最后都会落到账上。绿区两分，黄区一分，连中还能听见更厚的锤音。” |
| 1:40～2:30 | 接小荷、猎户的单，做到第一晚 | 先让观众自己听见小荷的口误。捕头登门时停一下，让观众看旧目标如何被划去 |
| 2:30～3:20 | 弯腰拾起账页，展示随身手记 | “我们把早期直接公布黑幕的方案改了。玩家完全可以不理会这张纸，只管赚钱。” |
| 3:20～4:15 | 展示录屏里秦军户、收据、最后选择，或用预先玩到最后一单的另一浏览器窗口 | “一份证据能让人起疑，三份证据和街坊的信任才让人有底气开口。” |
| 4:15～5:00 | 展示顾客回应标签、日志、提交历史 | 普通顾客的评语可接课程模型，柜上的账由本地规则决定。未配置 Key 时演示本地台词，接口测试中的模拟响应要明确说明 |

录屏含结局剧透。若现场准备在线模式，先在本机配置服务端环境变量，用实际生成的回应演示。组员信息按真实参与情况填写。
