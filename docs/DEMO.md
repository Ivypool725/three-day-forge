# 五分钟现场展示提纲（主讲人自行练习）

**内含剧透。**

| 时间 | 操作 | 可以讲的一句话 |
|---|---|---|
| 0:00～0:40 | 离线打开游戏，读老周的信 | “这是我第一次独立看店。师傅给了我三天，也留下一句别碰木箱。” |
| 0:40～1:40 | 点顾客进入对话，接单后使用炉膛、铁砧和水槽 | “绿区两分，黄区一分。每锤的绿区位置会变，不同委托的难度也不同。” |
| 1:40～2:30 | 接小荷、猎户的单，做到第一晚 | 先让观众自己听见小荷的口误。捕头登门时停一下，让观众看旧目标如何被划去 |
| 2:30～3:20 | 弯腰拾起账页，展示随身手记 | “我们把早期直接公布黑幕的方案改了。玩家完全可以不理会这张纸，只管赚钱。” |
| 3:20～4:15 | 展示小荷和农户的承诺，以及最终出现的担保选择 | “把合适的器物交给客人，再听他们把话说完。街坊肯替你作保，第三天就多一条路。” |
| 4:15～5:00 | 展示手记、存档和提交历史 | 可用存档对照不同选择。现场演示在线顾客对话时，读取实际生成的回复。 |

录屏含结局剧透。若现场准备在线模式，先在本机配置服务端环境变量，用实际生成的回应演示。组员信息按真实参与情况填写。
