# 定稿对照与验收路线（含完整剧透）

原始依据为小组《老周的铁匠铺：三日之约》世界观、剧情与游戏设计方案 V1.0。以下把人物掌握的事实、玩家发现它们的顺序和验收动作对应起来。

| 章节 | 在游戏中怎样核查 | 应当看到 |
|---|---|---|
| 架空大晟、景和二十三年、青溪县城西 | 新开一局，读封面、署名和师傅信 | 老周嘱托学徒独自看铺，交代寻医、三日查账、传授手艺和后院木箱。老周三日内均未露面 |
| 第一天看店 | 给刘农夫做锄头、小荷做菜刀、猎户做猎刀 | 小荷随口提回乡。无“发现线索”提示，手记也未解锁证物 |
| 第三单收工 | 听门响，点击接过公文 | 陈捕头拿私造军器施压，索银三十两，给出第三日黄昏期限。旧目标被划去 |
| 柜台边的账页 | 查看散页或直接熄灯 | 阅读才取得被涂改的账本，能看见预付二十两和墨下半个“甲”字；跳过则留待以后 |
| 第二天街坊与军户 | 刘农夫、新菜刀、秦军户旧佩刀；第四单后继续看店 | 陈捕头再来。追问秦军户才听到库存和军用甲片的差别；收下并查看印记才成物证。未追问仍能接单 |
| 第二夜木箱 | 开箱并重读师傅信 | 出现未完成的甲胄部件、半张烧毁的收据和锈布。此时不能得到完整收据。第二夜确认离开可进隐藏结局 |
| 第三日追查 | 第七单后再看箱底；错过的散页、包裹和木箱均可补查 | 完整收据写着“三副”“二十两”、孙承安及县衙押记。三证合看才拼出老周接单、卷款离去、留下徒弟的隐情 |
| 末单及对峙 | 交付外乡客的长刀，关门核账 | 陈捕头带两名官差来。按本局数据显示行动，揭露与交钱同时可用时由玩家决定 |

全部结局和逐单选择见[结局与触发条件（内含剧透）](ENDINGS.md)。

九单上限依次为 3、4、5、4、5、6、5、6、7 两。精良、合格、瑕疵分别实收 100%、80%、50%，口碑变化为 +3、+2、−3。现金用整数钱保存。初始 0 两、50 口碑，全精良 45 两、77 口碑，全合格 36 两、68 口碑，全瑕疵 22.5 两、23 口碑。

小组已采用玩家点击调查的分支。经营时间按交付推进；故事不要求玩家赶在读完台词前立刻操作。定稿以固定订单和手艺带来的交易收入维持经营，早期草案中的自定价、日常采购未沿用。
